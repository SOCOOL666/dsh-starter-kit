## 这是什么（一句话版）

这是一个 **DSH 插件合集**。它把三个经过大量用户验证的实用功能打包在一起，安装一次即可获得：

1. 🛒 **可视化插件市场**（dshmarket）—— 在 DSH 里逛商店，点一下就能装插件；
2. 🗂️ **增强侧边栏**（dsh-better-sidebar）—— 文件树、编辑器、Git、终端、子代理任务、侧边对话全在一个侧栏里；
3. ✍️ **全局提示词**（本整合包内置）—— 填一次提示词，之后每个新对话和子代理都自动带上。

对新手来说，你不必再去 GitHub 一个个搜插件、判断版本兼不兼容、研究怎么安装。**装这一个包，日常使用 DSH 需要的东西基本齐了。**

## 安装（小白向，一步一步来）

### 前提

- DSH 版本 ≥ **0.2.2-rc.2**（在 `0.2.2-rc.3` 上验证通过）
- Node.js ≥ 20

### 方式一：GitHub 网页版下载后安装（适合不想敲命令的新手）

1. 在本仓库页面点右上角 **Code → Download ZIP**，下载后解压到一个固定目录（例如 `D:\plugins\dsh-starter-kit`）。
2. 打开 DSH → **设置 → 插件 → 添加插件 / Add plugin**。
3. 选择刚才解压出来的 `dsh-starter-kit` 目录。
4. 安装完成，在插件列表确认 **DSH Starter Kit** 已启用。
5. **硬刷新浏览器**：`Ctrl+Shift+R`（Mac 为 `Cmd+Shift+R`）。这一步很关键，前端界面插件必须刷新才显示。

### 方式二：git clone 后安装

```bash
git clone https://github.com/SOCOOL666/dsh-starter-kit.git
```

在 DSH 的 **设置 → 插件 → 添加插件** 里选择 `dsh-starter-kit` 目录，然后硬刷新浏览器。

### 方式三：npm 安装（适合熟悉命令行的用户）

```bash
npm install -g dsh-starter-kit
```

安装后到插件管理页启用，再硬刷新浏览器。

## 安装后怎么用（每个插件的用处和入口）

### 1. 🛒 可视化插件市场 · dshmarket

**它是干什么的**：一个开在 DSH 里的应用商店。你想再装别的插件时，不用去 GitHub 搜，直接在这里浏览、搜索、一键安装。

**入口**：安装后到 **设置 → 插件**，会出现市场入口（左下角侧栏，主题为 DSH 设置页）。打开后你可以：

- 按分类或关键词浏览社区插件；
- 点「安装」直接装，无需手动敲命令；
- 查看插件介绍、星标、作者信息。

**什么时候用**：以后你想给 DSH 加新功能（比如语音输入、主题皮肤、特定工作流），第一站就来这里逛。

> 数据：⭐ 12,897，月下载 1,270,308 —— 它是 DSH 生态里最主流的插件市场。

### 2. 🗂️ 增强侧边栏 · dsh-better-sidebar

**它是干什么的**：把 DSH 的侧边栏变成一个真正的"工作台"。默认 DSH 侧栏主要是对话列表，这个插件在右侧塞进了一整套开发工具。

**入口**：安装后看界面**右侧栏**的一系列标签页（配置入口在 **设置 → Side card（左下角）**）。主要功能：

| 标签页 | 能做什么 |
| --- | --- |
| 📂 文件 | 文件树（带 Git 状态颜色）、全局搜索、拖拽上传、多选批量操作、在编辑器里直接改文件并保存 |
| 🌿 Git | 源代码管理（暂存区、变更、提交信息）、只读提交图谱（分支、标签、提交详情） |
| 📝 编辑器 | 可编辑的 CodeMirror 编辑器（原生预览是只读的）、Markdown + Mermaid 预览、HTML 沙箱预览 |
| 🧩 任务 | 实时子代理拓扑图、后台任务列表（退出码、实时输出、强制结束） |
| 💬 侧边对话（beta） | Codex 风格的旁支对话：继承当前上下文独立运行，可一键提升为顶层会话 |
| 🖥️ 底部工作台 | 可拖拽分栏的多面板、多终端标签页（终端由 DSH 自身提供） |

**什么时候用**：改代码、看 Git 变更、管理文件、盯子代理任务时——不用在对话和文件管理器之间来回切。

> 数据：⭐ 5,235，月下载 361,958，拥有 30+ 生态扩展。

### 3. ✍️ 全局提示词（本包内置）

**它是干什么的**：让一段提示词对所有新对话自动生效。比如你希望"始终用中文、回答简洁、末尾列依据"，填一次，以后每次都自动带上，不用复制粘贴。

**入口**：**设置 → 通用设置 → 全局提示词（一键包内置）**。

**用法**：

1. 在文本域输入你的提示词，例如：
   ```text
   始终使用简体中文回复。回答简洁、有条理，并在末尾列出关键依据。
   ```
2. 点「保存」，看到「已保存」即成功。
3. 从现在起，**新建的对话**和**子代理**的 System Prompt 都会自动包含这段内容。
4. 想关闭：清空文本域再点「保存」即可。

**特点**：通过 `ctx.systemPrompt.section()` 注入，不写进对话历史、不重复占用上下文；保存后下一次请求即生效，无需重启 DSH；内容持久保存在当前 profile。

## 关于"装一个就够"的说明（请理性看待）

这个整合包的目标，是让新手**开箱即用、日常不再到处找插件**。装完后：

- ✅ 逛插件、装插件 → 用市场（不用去 GitHub 搜）
- ✅ 文件编辑、Git、终端、子代理任务 → 用增强侧边栏
- ✅ 全局提示词 → 用内置功能

需要如实说明的是：**没有任何一个整合包能保证你"永远不需要装别的"**。DSH 生态有数百个插件，未来你可能会有更专门的需求（特定语言模型、垂直工作流、冷门工具）。这个包的价值在于：

- 把**最高频、最通用**的三件事一次配好；
- 内置的插件市场让你**以后想装什么都方便**，不必再学安装流程。

所以更准确的说法是：**装完这一个，日常使用 DSH 的基本盘就齐了；以后要扩展，市场就在手边。**

## 常见问题

- **装完看不到侧边栏/市场？** 一定要硬刷新浏览器（Ctrl+Shift+R）。前端插件不刷新不会出现。
- **提示词保存失败？** 检查当前 profile 的 `cordis.patch.yml` 是否可写。
- **两个侧边栏？** 如果你以前手动装过 dsh-better-sidebar，删掉 profile 里旧的手动挂载行，避免和本包重复挂载。
- **提示词对新对话生效，旧对话没有？** 正常。本包只影响保存之后的新对话/新请求，不回改历史。

## 安全提示

本整合包集成的 `dsh-better-sidebar` 从 v0.23.0 起，其文件读写路由**不做工作区隔离**（仅受操作系统权限约束），并带有 HTML 沙箱预览等能力。它是 MIT 许可的社区插件、功能强大，但也意味着较大的文件访问面。介意的话可在其设置中关闭相关能力，或单独卸载该插件。
